# Spotify Clone Music Player

A lightweight Spotify-inspired music player built with HTML, CSS, and JavaScript. This project recreates the feel of a modern music streaming app with a sleek dark interface, album-style cards, a sidebar library, and full audio controls.

## Why this project is a great one

This project stands out because it combines a polished user experience with practical web development concepts:

- Modern Spotify-inspired design with a clean dark theme
- Interactive music player with play, pause, next, previous, shuffle, and repeat controls
- Dynamic song library that loads from a local music collection
- Playlist-style card layout for a premium streaming look
- Responsive interface that adapts well to different screen sizes
- Easy to understand and customize for learning or personal projects
- Front-end-only implementation that is lightweight and fast to run

## Main Features

- Elegant two-column layout inspired by Spotify
- Sidebar library with song list and active track highlighting
- Large album card section for browsing tracks
- Current song information panel in the bottom player
- Seek bar and volume control
- Like button interaction
- Built-in audio playback support for local MP3/M4A files
- Simple project structure for easy modification

## Project Structure

- `index.html` – App layout and player UI
- `style.css` – Styling and Spotify-like theme
- `utility.css` – Additional utility classes
- `script.js` – Audio logic, interactions, and UI updates
- `covers/` – Album cover artwork
- `MUSIC/` – Music files used by the player
